# StockPilot

Sistema inteligente de gestão e análise operacional para pequenos e médios negócios.

## Objetivo

Centralizar informações operacionais e financeiras, oferecendo análises e recomendações por meio de um agente de inteligência artificial.

## Tecnologias

- Java
- Spring Boot
- Python
- PostgreSQL
- API REST
- JUnit
- Pytest
- Git
- GitHub
- Docker

## Arquitetura

Monólito modular em Java com serviço independente de inteligência artificial em Python.

## Estrutura

- backend/: aplicação principal Java
- ai-service/: serviço de inteligência artificial
- database/: scripts e migrações do banco
- docs/: documentação do projeto
